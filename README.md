# 💰 Who Wants to Be a Millionaire - Python GUI

Aplikasi kuis interaktif bertema **Who Wants to Be a Millionaire** yang dibuat menggunakan **Python** dan pustaka bawaan **Tkinter**. Dilengkapi dengan antarmuka mode gelap (dark mode), animasi transisi tombol, struktur hadiah berjenjang, dan fitur bantuan (Lifeline 50:50).

## 🚀 Fitur Utama
- **Modern Dark UI**: Tampilan elegan bergaya studio kuis televisi.
- **Dynamic Questions**: Bank soal dimuat secara eksternal melalui file `questions.json` sehingga mudah dikustomisasi.
- **Lifeline 50:50**: Fitur bantuan untuk menghilangkan 2 jawaban salah.
- **Prize Tracker**: Panel di sisi kanan untuk memantau akumulasi hadiah setiap naik level.

2. Unduh atau *clone* repositori ini.
